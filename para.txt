12. GITHUB PAGES HOSTING STEPS
--------------------------------------------------------

1. Create a public GitHub repository.

2. Name the repository appropriately.

3. Upload:

   index.html
   style.css
   script.js
   documentation.txt

4. Go to:

   Repository → Settings → Pages

5. Select:

   Deploy from a branch

6. Select:

   Branch: main

7. Select:

   Folder: / (root)

8. Click Save.

9. Wait for GitHub Pages to publish the website.

10. Open the generated website URL.
